# API Description

## Назначение

API предназначен для взаимодействия клиентской части системы с серверной частью.

В рамках учебного проекта спроектированы основные endpoints для работы с расписанием, записями учеников и домашними заданиями.

## Lessons

### Получение списка занятий

```text
GET /lessons
```

**Назначение:**

Получение списка доступных занятий.

**Успешный ответ:**

```text
200 OK
```

---

### Получение занятий ученика

```text
GET /students/{student_id}/lessons
```

**Назначение:**

Получение списка занятий, на которые записан конкретный ученик.

**Успешный ответ:**

```text
200 OK
```

## Enrollments

### Запись ученика на занятие

```text
POST /enrollments
```

**Тело запроса:**

```json
{
  "student_id": 1,
  "lesson_id": 101
}
```

**Успешный ответ:**

```text
201 Created
```

**Возможные ошибки:**

```text
400 Bad Request
401 Unauthorized
409 Conflict
```

Код `409 Conflict` может использоваться, если ученик уже записан на выбранное занятие.

---

### Отмена записи

```text
DELETE /enrollments/{id}
```

**Назначение:**

Удаление записи ученика на занятие.

**Успешный ответ:**

```text
200 OK
```

При нарушении ограничения по времени операция должна быть отклонена.

## Homework

### Получение домашнего задания

```text
GET /lessons/{lesson_id}/homework
```

**Назначение:**

Получение домашнего задания для выбранного занятия.

**Успешный ответ:**

```text
200 OK
```

---

### Добавление домашнего задания

```text
POST /lessons/{lesson_id}/homework
```

**Тело запроса:**

```json
{
  "description": "Complete exercises 1-5"
}
```

**Успешный ответ:**

```text
201 Created
```

**Возможные ошибки:**

```text
401 Unauthorized
403 Forbidden
404 Not Found
```

Код `403 Forbidden` может использоваться, если пользователь не имеет прав преподавателя.

## Основные HTTP-коды

| Код | Значение |
|---|---|
| 200 | Запрос успешно выполнен |
| 201 | Ресурс создан |
| 400 | Некорректный запрос |
| 401 | Пользователь не авторизован |
| 403 | Недостаточно прав |
| 404 | Ресурс не найден |
| 409 | Конфликт |
