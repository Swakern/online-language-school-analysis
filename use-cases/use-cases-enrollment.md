# UC-01 — Запись ученика на занятие

## Название

Запись ученика на занятие

## Актор

Ученик

## Цель

Записаться на выбранное занятие.

## Предусловия

- ученик зарегистрирован в системе;
- ученик авторизован;
- занятие существует в расписании;
- занятие доступно для записи.

## Постусловия

- ученик записан на выбранное занятие;
- информация о записи сохранена;
- количество свободных мест обновлено.

## Основной сценарий

1. Ученик открывает личный кабинет.
2. Система отображает расписание доступных занятий.
3. Ученик выбирает необходимое занятие.
4. Ученик нажимает кнопку «Записаться».
5. Система проверяет наличие свободных мест.
6. Система отображает окно подтверждения записи.
7. Ученик подтверждает запись.
8. Система создаёт запись ученика на занятие.
9. Система обновляет количество свободных мест.
10. Система отображает сообщение об успешной записи.
11. Сценарий завершается.

## Альтернативный сценарий A1 — Нет свободных мест

1. Система проверяет количество свободных мест.
2. Система определяет, что свободных мест нет.
3. Система сообщает ученику об отсутствии свободных мест.
4. Система предлагает выбрать другое занятие.
5. Ученик выбирает другое занятие.
6. Сценарий возвращается к выбору занятия.

## Альтернативный сценарий A2 — Повторная запись

1. Система проверяет существующие записи ученика.
2. Система определяет, что ученик уже записан на выбранное занятие.
3. Система отображает сообщение о существующей записи.
4. Новая запись не создаётся.
5. Сценарий завершается.

## Альтернативный сценарий A3 — Занятие отменено

1. Ученик выбирает занятие.
2. Система проверяет статус занятия.
3. Система определяет, что занятие отменено.
4. Система сообщает ученику, что запись недоступна.
5. Новая запись не создаётся.
6. Сценарий завершается.
