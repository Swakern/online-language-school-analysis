# Business Rules

**BR-01. Свободные места**

Ученик может записаться только на занятие, в котором есть свободные места.

**BR-02. Повторная запись**

Ученик не может дважды записаться на одно и то же занятие.

**BR-03. Отменённое занятие**

Отменённое занятие недоступно для записи.

**BR-04. Управление домашним заданием**

Только преподаватель может добавлять, изменять и удалять домашнее задание.

**BR-05. Просмотр домашнего задания**

Ученик может просматривать домашнее задание только для своих занятий.

**BR-06. Управление расписанием**

Администратор может создавать, изменять и отменять занятия.

**BR-07. Ролевой доступ**

Пользователь может выполнять только те действия, которые разрешены его ролью.

**BR-08. Статистика**

Руководитель может просматривать статистику и отчёты, но не изменяет данные о занятиях и записях учеников.

**BR-09. Домашнее задание для отменённого занятия**

Преподаватель не может добавить домашнее задание к уже отменённому занятию.

**BR-10. Удаление занятия**

Администратор не может удалить занятие, на которое уже записаны ученики.

**BR-11. Отмена записи**

Ученик может отменить запись не позднее чем за 24 часа до начала занятия.
