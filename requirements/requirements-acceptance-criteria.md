# Acceptance Criteria

## US-02 — Просмотр домашнего задания

1. Если ученик авторизован, система предоставляет ему доступ к личному кабинету.
2. В личном кабинете ученик может просматривать свои занятия.
3. Занятия, для которых существует домашнее задание, должны быть доступны для просмотра задания.
4. При выборе занятия система отображает домашнее задание, добавленное преподавателем.
5. Если домашнее задание отсутствует, система сообщает об его отсутствии.
6. Ученик не может изменять или удалять домашнее задание.

## US-03 — Запись на занятия

1. Авторизованный ученик может открыть расписание.
2. Система отображает доступные занятия.
3. При выборе занятия система проверяет наличие свободных мест.
4. Если свободные места есть, система предлагает подтвердить запись.
5. После подтверждения система создаёт запись ученика.
6. Если свободных мест нет, система сообщает об этом и не создаёт запись.
7. Ученик не может записаться на одно занятие повторно.
